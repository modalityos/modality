# SceneSettings

A Settings window over the default wallpaper, built only from the Tokens: a frosted sidebar (`material-sidebar-*`), grouped rows on `surface-raised`, a segmented control, pop-up button, toggles and a slider on `fill`, and primary and secondary buttons. The secondary button shows the focus ring. A scene for judging the look; the Controls themselves are designed later. Window controls are ModalityOS's own.
