# SceneLogin

A login screen over the default wallpaper, built only from the Tokens: the date in `title-1`, the clock in `display`, an avatar at `avatar-size-large`, a pill password field on `material-popover-*` showing the focus ring, a Caps Lock hint in `warning`, and Sleep, Restart and Shut Down. A scene for judging the look; the Greeter itself is designed next, on these Tokens. In the Greeter the materials fall back to solid colours, since Cage cannot blur.
