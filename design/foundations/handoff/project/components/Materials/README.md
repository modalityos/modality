# Materials

The three translucent materials, each shown over a busy background with its blur, then as its solid fallback. A specimen of the `material-*` Tokens, not a Control.

Blur is a compositor effect. Where it is missing, or Reduce transparency is on, use the `*-fallback` colour; every text Token holds contrast on it. The Greeter runs in Cage, which cannot blur, so it blurs its own wallpaper instead.
